# Vier Gewinnt im Browser

Ein einfaches Vier-Gewinnt-Spiel für den Webbrowser. Du spielst als **Rot** gegen den Computer (**Gelb**).

## Features

- 7x6 Spielfeld
- Mensch gegen Computer
- Einfache KI mit:
  - direktem Gewinnzug
  - Blocken gegnerischer Gewinnzüge
  - leichter Positionsbewertung (Mitte bevorzugt)
- Gewinnerkennung und Unentschieden
- Neustart-Button

## Starten

1. Repository klonen oder Dateien herunterladen.
2. `index.html` im Browser öffnen.

Kein Build-Schritt erforderlich.
